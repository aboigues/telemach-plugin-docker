# Catalogue d'erreurs Docker

Chaque fichier `*.yaml` de ce répertoire regroupe les erreurs d'une catégorie (`network`,
`image`, `container`…). Le contenu pédagogique est rédigé **en français**.

Le format et les règles de validation sont décrits dans
[`docs/catalogue.md`](../../../docs/catalogue.md) et vérifiés par
`internal/catalog/catalog_test.go`.
